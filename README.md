Сайт - https://stackoverflow.com/

Сайт - https://codepen.io
Примеры реализации структуры c ES-modules, реализация анимации Canvas 2D API

Статья - https://proglib.io/p/25-poleznyh-snippetov-javascript-dlya-vashey-kollekcii-2020-11-29
